## 已确定的制作规格

45 秒、16:9 横屏、720p，二维国风武侠、赛璐璐上色。只使用用户提供的视频 32:00–34:00，按原事件顺序选取九个五秒片段。保留原片服装配色、兵器和主要动作，最终配回精剪原声音轨，不增加新对白。

使用灯虹开发站 `https://dev-aicanvas.qnlinking.com`。凭证仅从用户本机环境读取，不保存在仓库。用户配置文件默认站点可能仍为正式站；每次本项目调用必须显式设置开发站 Host。

视频模型为 Seedance 2.0-mini，720p。按当前开发站报价，参考视频输入和视频输出各 39 积分/秒：一个五秒样片为 390 积分，九段共约 3510 积分。样片合格后计入总长；本次总上限 5000 积分，未分配余量 1490 积分不自动消费。详情见[费用记录](费用记录.json)及[sample-quote.json](sample-quote.json)。

Mini 支持参考视频生成，不是逐帧编辑模式。动作、镜头和人物一致性必须通过样片实测；失真或审核失败时停止，不自动换模型、重复提交或扩大预算。
